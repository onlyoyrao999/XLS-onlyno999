# XLS-onlyno999

微信小绿书（公众号贴图号）· 旅游自拍通用打造 Agent

> 使用者只给两样东西：一张定妆照 + 答完 Agent 设计的咨询问卷。剩下的定位、人设、选题、穿搭、文案、排期，全部由 Agent 设计。

## 这是什么

一个工作流技能（Agent Skill），专做微信公众号「图片/文字」贴图形态（俗称小绿书）：

每篇 = 一组主角在某地的**旅游自拍照**（6-9 张，3:4）+ 一段短文案，吃公众号推荐流，靠流量主 + 返佣带货变现。

**无默认主角**，一人一档：脸按定妆照 1:1 锁死，衣服每篇按目的地/季节/场景重新搭配，就像主角真的出门旅游拍的自拍。

不做：表情包、公众号长文章、视频。

## 使用流程

```
传入定妆照
  → Phase 1 咨询建档：Agent 分三轮提问（18 题）
      第一轮 人是谁（称呼/身份/性格/说话风格/招牌元素/锁定项）
      第二轮 号做什么（常驻地/旅行风格/目标粉丝/做号目的/愿望清单）
      第三轮 风格与运营（穿搭雷区/自拍尺度/禁忌/更新频率/变现品类）
      ※ 只有称呼、性格、做号目的 3 题必答，其余答不出由 Agent 给默认值并标注「假设项」
  → Phase 2 人设蓝图：号名 3 选 1 / 头像简介 / 口吻样例 / 锁变清单 / 支柱配比 / 专属穿搭 / 首月路线
      使用者确认后锁定 persona.md，不再重复咨询
  → Phase 3 每篇生产：周排期 → 立项卡 → 锁脸生图（先出封面验脸）→ 文案 → 发布包 → 周复盘
```

## 核心铁律

0. **只能本人手动发布（最高优先级）**：严禁自动发布、严禁半自动发布——不代发、不代登录、不代存草稿、不代填表单、不设定时预约；Agent 只交付发布包，发表由账号本人亲手完成，此铁律不因授权豁免。
1. **脸锁死**：每张图必须带定妆照原图作参考锁脸，先出封面张、放大裁脸验过才批量生产，漂移不交付。
2. **衣随景换**：服装不锁，每篇重搭；连续 3 篇穿搭无变化 = 不合格。
3. **自拍逻辑**：每篇 ≥3 张真自拍视角，地标在背景可辨认、人在前景；拒绝影楼摆拍、图内不烧中文文字。
4. **合规**：景点事实查证了才写；虚构人设不编造可核验的假经历；不蹭灾难/敏感事件。
5. **一人一档**：多个主角各自建档，脸、穿搭、口吻绝不串档。
