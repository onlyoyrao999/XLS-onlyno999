# 建号、发布与变现

> 平台规则会变：涉及粉丝门槛、入口位置的数字，执行时以公众号后台/订阅号助手当时显示为准；本文件写的是流程与判断线，不把数字当承诺。

## 0. 建号（没有公众号时）

1. 入口：mp.weixin.qq.com → 立即注册 → 订阅号 → 个人主体。一个身份证只能注册 1 个个人订阅号，注册前想清楚，别乱占名额。
2. 备料：未注册过公众号的邮箱、身份证、本人实名微信（扫脸）、手机号。
3. 命名：用蓝图定的号名；重名就按蓝图候补顺序换，号名一年只能改 2 次，不许随手填。
4. 头像/简介：按蓝图上传（头像=定妆照正脸裁切），简介照抄蓝图定稿。
5. 建完号先发 1 篇「开号篇」：主角在常驻地地标的自拍组 + 自我介绍文案（把人设一句话展开），置顶自我介绍。

## 1. 发布（每篇，订阅号助手 APP，全程本人手动）

> **发布铁律：只能本人手动发布。严禁自动发布，严禁半自动发布。** 以下每一步都由账号本人亲手操作；Agent 只交付发布包，不代登录、不代存草稿、不代填表单、不设定时/预约发表。此铁律不因使用者授权而豁免。PC 后台发布同理。

1. 打开订阅号助手 → 发表 → 选「图片/文字」（小绿书形态，不要选长文章）。
2. 按发布包顺序选图 01→09，第一张即封面（已在立项时定好）。
3. 粘贴 `publish.txt` 的标题与正文、补标签；地点能标就标（地标篇标真实地点）。
4. 预览一遍：图序、错字、脸有没有被裁掉头——确认后发表。
5. 发布时间按人设卡（默认 19:30，午间备选 12:00），定了就固定，不要一天一个点。

PC 备选：公众号后台 → 新的创作 → 图片/文字，字段同上。

## 2. 变现路线（按人设卡的第一目的排）

- **流量主（默认第一站）**：粉丝达后台门槛（历史上 500、近年有 100 的说法，以后台开通页为准）即开通，贴图号主要吃文中/底部与留言区广告。没达标前不焦虑，先攒内容到 30 篇。
- **返佣带货**：小绿书可挂商品链接返佣（旅行类：防晒、便携用品、当地特产、人设同款配饰），选品只选与人设/场景真相关的，文案规则见 copywriting.md 带货条。
- **付费内容/商单**：粉丝与阅读稳定后再开；接商单只接与人设不冲突的品类（Q18 雷区不接），并按平台要求标注。
- **引流型人设**（第一目的是给店/业务引流）：内容里只做场景植入与主页简介承接，不写违规导流话术，细则按平台当时规范执行。

## 3. 数据复盘（每周）

看四项，只看公众号后台「内容分析」里贴图的数据：
- **推荐阅读占比**：靠推荐流起号，占比持续 <30% 说明选题/封面不吃推荐，先换封面张与标题公式。
- **点开率**：封面+标题的成绩。低了先动这两样，不动正文。
- **互动率（赞+评/阅读）**：<1% 说明互动问句太空泛，换具体问句；评论区每篇至少回复前 5 条，由使用者本人手动回复（ Agent 只提供回复草稿文本，不登录代回）。
- **单篇流量主收入**（开通后）：只看趋势找高效支柱，不看绝对值做决策。

判断线：爆款=阅读 > 近 7 天均值 3 倍 → 48h 追续集；某支柱连 5 篇阅读 <100 → 暂停一周；连 3 篇点开率垫底 → 下周排期先做封面 A/B（同题两版封面自选更强者）再继续。

## 4. 账号安全

- **发布只许本人手动**：严禁自动/半自动发布（脚本/API/自动化代发、定时预约、代存草稿、代填表单都算违规操作）；账号登录、实名、收款等敏感操作永远由使用者本人完成，Agent 只交材料与步骤，不保管密码与登录态。

- 不刷量、不互推群发、不买粉：贴图号推荐流权重吃真实互动，刷量毁号。
- 不搬运他人图片冒充主角自拍；本号图只用本项目锁脸生产的图。
- 账号登录、实名、收款等敏感操作永远由使用者本人完成，Agent 只交材料与步骤。
