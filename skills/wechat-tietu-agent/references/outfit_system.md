# 穿搭系统（衣随景换）

总原则：**脸锁死，衣随景换。** 每篇按目的地/季节/场景 + 人设卡的专属穿搭系统重新搭配。连续 3 篇无变化 = 不合格。雷区（人设卡 Q12）一条不碰。

## 搭配公式（一篇一套，写进立项卡）

`穿搭 = 场景基调款 + 人设主色 1 件 + 中性色打底 + 招牌元素（按锁定清单）+ 1 件季节/功能件`

- 全套必须写全：上装 / 下装 / 鞋 / 帽（或无帽）/ 配饰 / 背包或手持道具，缺项视为没设计。
- 配色：全身 ≤3 个主色；人设主色每篇至少出现 1 次（上衣、帽子、围巾、包任选其一），保证刷到任意一篇都认得出是同一个人设系列。
- 季节真实：夏天不穿羽绒、雪天不穿短袖——穿错季节比穿丑更出戏，直接不合格。

## 按场景基调表（通用，套人设主色使用）

| 场景 | 基调款 | 鞋 | 配饰/道具 | 忌 |
|---|---|---|---|---|
| 山野户外 | 冲锋衣或速干外套+工装裤 | 登山鞋/运动鞋 | 双肩包、水壶、登山杖（可选） | 皮鞋、正装、白裤（易脏出戏） |
| 海边湖边 | 浅色衬衫/速干T+短裤或轻薄长裤 | 凉鞋/洞洞鞋/帆布鞋 | 草帽或渔夫帽、墨镜（可挂胸前） | 全黑厚重、长靴 |
| 古镇老街 | 亚麻衬衫/新中式上衣+休闲长裤 | 布鞋/小白鞋 | 帆布包、折扇或相机（按人设） | 大 logo 潮牌、荧光色 |
| 城市街头 | 按人设基调：街头款/简约款/质感款 | 与基调同系 | 斜挎包、地铁卡、咖啡杯道具 | 与人设基调冲突的正装/睡衣感 |
| 美食市集 | 耐脏深色或格纹上衣+围裙感配饰（可选） | 好走的鞋 | 手拿招牌食物就是最好的道具 | 白色上衣怼油点子（除非搞笑翻车篇故意） |
| 雪景冬季 | 羽绒/棉服（主色款）+保暖裤 | 雪地靴 | 针织帽、围巾、手套三件套齐 | 露脚踝、单衣 |
| 节气节日 | 带节气色：樱花粉点缀/红叶季大地色/年节红点缀（≤1 件红） | 同场景 | 节气小物：灯笼、年货袋、花束 | 从头红到脚、 cosplay 化 |

## 招牌元素处理

- 人设卡 LOCK_LIST 写「每篇保留」的：默认每篇出镜；场景表里有更适配的头部装备时（如雪山针织帽替棒球帽）可换，但立项卡必须注明「本篇招牌替换：X→Y，原因：场景」。
- 写「可有可无」的：Agent 自由决定，保证每月至少 1/3 篇次出镜维持辨识度。
- 没有招牌元素的：Agent 在蓝图阶段建议 1 个（帽子/眼镜/固定背包/固定手势四选一），使用者点头后写入锁定清单——没有辨识锚点的旅游号很难被记住。

## 人设风格微调（举例，实际以人设卡为准）

- 接地气/穷游：耐穿耐脏、重复单品可复用（同一件外套多篇出现反而真实），忌全身名牌感。
- 精致轻奢：面料质感词写进提示词（羊毛、真丝感、剪裁合身），忌大 logo、忌配色超过 3 色。
- 搞笑整活：允许 1 件夸张单品（花衬衫、搞怪帽），但脸和其余搭配保持正常，别整成小丑。
- 温柔治愈：低饱和、针织/棉麻质地，忌硬朗工装与荧光。
- 年长人设：合身、稳重色、舒适鞋优先，忌硬套年轻潮牌。
