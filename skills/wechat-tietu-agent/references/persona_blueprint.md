# 人设蓝图 / persona.md 模板

问卷答完后 Agent 按此模板设计蓝图，使用者确认后存为 `PROJECT_DIR/persona.md` 并标 `状态: LOCKED（<日期>）`。生产阶段一切以此卡为准。

```markdown
# 人设卡 · <PERSONA_NAME>
状态: DRAFT / LOCKED（YYYY-MM-DD）
定妆照: assets/face_ref.<ext>（补充图: ...）
肖像授权确认: 是（YYYY-MM-DD 本人/已授权）

## 1. 账号（3 选 1，给推荐项和理由）
- 号名候选: ①<称呼+旅行词> ②<...> ③<...>；推荐 ①，理由一句
- 头像: 定妆照正脸裁切（圆图安全区说明），不加文字
- 简介定稿: 一句话——跟着<称呼><做什么>（如：跟着刁哥自拍打卡全国，一个普通人的旅行相册）
- 背景图/菜单: 可选，一句建议即可

## 2. 人设一句话
<称呼> = <年龄段>的<身份标签>，<背景故事一句>，性格<3词>。
类型: 真实本人 / 虚构人设（注明）

## 3. 口吻
- 自称: <我/老X/昵称>；称粉丝: <朋友们/家人们/自定义>
- 语言: 普通话 / <方言>点缀（浓度: 轻/中）
- 口头禅: <...>；样例文案一条（80-120 字，按真实口吻写，供确认语感）

## 4. 锁定 vs 可变
- LOCK_LIST（锁死）: 脸（以定妆照为准）、年龄感、<招牌元素>、<使用者指定项>
- FREE_LIST（可变）: 服装（每篇重搭）、配饰、发型小幅变化（若未锁定）、场景、表情动作

## 5. 内容支柱配比（合计 100%）
地标打卡 __% / 山野户外 __% / 城市街头 __% / 美食市集 __% / 节气节日 __%
配比依据: 主风格<..>+副风格<..>+目标粉丝<..>（一句话）

## 6. 专属穿搭系统
- 主色调: <2-3 色>；避雷: <不穿的/讨厌色>
- 基调: <风格词>；按场景基调表（海边/山野/古镇/城市/美食各一行，细表见 outfit_system.md 按此基调套用）
- 招牌元素用法: 默认保留 / 可换场景清单

## 7. 首月路线图
第 1 周: <愿望清单前 2 + 当季 1>；第 2-4 周: 每周一行（目的地+支柱+钩子）
常驻地日常备选池: <3 个近郊/市内点，断档时用>

## 8. 运营与变现
- 节奏: <频率>，发表时间 < >，发表人: 使用者（发布包制）
- 第一目的: <Q10 第一位>；变现路线: 流量主（粉丝达标即开）→ <带货品类/商单/引流，按目的写>
- 禁忌清单: <Q14 + 默认红线>

## 假设项清单（Agent 默认、使用可随时改）
- <逐条列：题号 + 默认了什么>
```

## 设计要点（Agent 自检）
- 号名带称呼+旅行/自拍语义，≤10 字好记，不与大号重名（出蓝图前搜一遍公众号重名情况，能搜则搜）。
- 支柱配比必须能从问卷答案推出，不许套用与人设无关的平均分配。
- 样例文案是语感试金石：使用者说「不像他说话」就先改口吻再往下，不许带着错口吻量产。
- 穿搭主色从定妆照肤色/气质 + Q12 偏好推，避雷项一条不碰。
