# 咨询问卷（Intake Questionnaire）

调用本 Agent 的第一步。目的：使用者只提供定妆照 + 答这 18 题，Agent 就能完成其余全部设计。
执行方式：默认分三轮在聊天里问（一轮问完、复述确认、再下一轮）；使用者说「一次发我填」时，把本文件三轮题目整理成表单一次发完。
原则：题题有「为什么问 / 默认值」。标 ★ 的 3 题（Q2/Q5/Q10）无默认、必须问到；其余答不出就按默认执行并记入蓝图「假设项清单」。

## 开场白（照此意思说）

> 可以，我来帮你从零打造。先给我一张主角的定妆照（正脸清晰、不要美颜过度的），再答我三轮小问题——人是谁、号做什么、喜欢什么风格。答完我直接给你一套人设方案：号名、定位、穿搭、首月去哪拍，你点头咱们就开工。

收定妆照时必问一句并记录答案：「这张是本人，或者你已拿到肖像授权，对吗？」答否/含糊 → 停，先解决授权再继续。
收图后动作：建 `PROJECT_DIR`，原图存 `assets/face_ref.<ext>`，检查清晰度（正脸、五官无遮挡、无重美颜）；不合格当场请补一张，不将就。

## 第一轮 · 人是谁（Q1-Q6，必填轮）

**Q1 定妆照**：除主图外，有侧面/全身照更好（选填，锁身材与发型用）。
- 记录：主图路径、补充图路径。

**Q2 ★ 称呼**：主角在号里叫什么？（真名、昵称、网名都行，如「刁哥」「小满」「老周」）
- 为什么：号名、文案自称、粉丝称呼全靠它。无默认。

**Q3 形象基准**：年龄段、性别呈现、体型——以定妆照为准由 Agent 描述、使用者确认即可，不用自己填。
- 追问一句：年龄感要不要冻住在这张照片的状态？（默认：是，全号不显老不显嫩。）

**Q4 身份标签**：主角是什么人？选/填：职业或生活身份（如外卖小哥、宝妈、大学生、退休教师、民宿老板……）+ 一句背景故事（如「攒钱三年，决定每月出门玩一次」）。
- 真实身份还是虚构人设？必须选一并记录（虚构的在蓝图注明，文案不冒充真实资历）。
- 默认：无。答不出时 Agent 按形象气质给 3 个标签候选让他挑。

**Q5 ★ 性格与说话**：用 3 个词形容性格（如接地气、话痨、冷幽默、温柔、社牛、慢热）；说话风格：普通话还是带方言味（哪里的、几分）、有没有口头禅。
- 为什么：决定全部文案口吻。无默认。答不出时 Agent 给两组候选词让他二选一，不许空转。

**Q6 招牌与底线**：有没有一眼认出他的招牌元素？（帽子/眼镜/发型/配饰/招牌动作/随身道具）招牌是每篇都保留，还是可以换？
- 绝不能改的还有什么（默认锁定：脸、年龄感；其余听他的）？服装默认每篇可换，确认一句：「衣服我每篇按场景给你重新搭，可以吧？」

第一轮收尾复述：「所以主角是——<称呼>，<年龄段><身份标签>，性格<3词>，招牌是<元素>，脸和<锁定项>锁死、衣服我来搭。对吗？」

## 第二轮 · 号做什么（Q7-Q11）

**Q7 常驻地与范围**：平时住哪个城市？旅行范围：省内 / 全国 / 全球？内容里的「旅行」默认从常驻地出发辐射。
- 默认：全国。

**Q8 旅行风格**：主风格 1 个 + 副风格 1 个，从这组挑：穷游接地气 / 精致轻奢 / 山野户外 / 美食探店 / 古镇文化 / 城市潮流 / 治愈慢游 / 搞笑整活。
- 为什么：决定支柱配比和选景审美。

**Q9 目标粉丝**：最想让谁看？（同龄人/同职业/宝妈/打工人/学生/中老年……可多选，给一个最主要的）
- 默认：与主角同身份人群 + 泛旅行人群。

**Q10 ★ 做号目的**：按重要程度排：流量主广告分成 / 带货返佣 / 涨粉后接商单 / 给自己的店/业务引流 / 先做 IP 人设再说。
- 为什么：决定变现设计与内容里带不带货。无默认，必须排第一位的那一个。

**Q11 愿望清单**：最想去、先拍哪 5 个地方？（城市/景点/场景都行）
- 默认：Agent 按 Q7/Q8 补满 5 个当季热门地，记为假设项。

第二轮收尾复述：「号定位——以<常驻地>出发、<主风格>风，主给<目标粉丝>看，第一目的是<目的>，先打卡<5地>。对吗？」

## 第三轮 · 风格与运营（Q12-Q18，多为确认/默认题）

**Q12 穿搭偏好**：喜欢的穿搭风格（运动休闲/街头/民族风/简约质感/甜美/酷飒……）、喜欢与讨厌的颜色、绝对不穿的（如裙装/西装/花哨图案）。
- 默认：授权 Agent 按场景自由搭配（只避他的雷区）。这一题本质是划雷区，不是让他自己当造型师。

**Q13 自拍风格**：表情动作尺度——自然抓拍派，还是可以搞怪夸张？常驻配角要不要出镜（伴侣/朋友/孩子/宠物，有则各自补定妆照建档）？路人临时出镜默认虚化/背影。
- 默认：自然抓拍 + 偶尔搞怪；无常驻配角。

**Q14 内容禁忌**：不想拍的题材、不想碰的话题、不出镜的场景（如喝酒、夜店、宗教场所内景）。使用者自己的红线优先于一切选题。
- 默认红线（不问也要执行）：不蹭灾难与敏感事件、不编造景点信息、不写极限违禁词。

**Q15 语言细则**：文案长短偏好（默认 80-180 字）、要不要 emoji（默认少量）、方言浓度（按 Q5，默认点缀不堆砌）。

**Q16 公众号现状**：已经有公众号了吗？（有：号名发我，我按现有号适配；没有：蓝图里 Agent 给 3 个号名候选，注册步骤见 publish_and_monetize.md 第 0 节）

**Q17 更新节奏**：日更 / 隔日更 / 一周 3 篇？发布时间偏好？
- 默认：隔日更、19:30 发表；发表由使用者在订阅号助手完成（Agent 交发布包）。

**Q18 变现细则**：（Q10 选了带货/引流才细问）愿意带的品类、不接的品类、要不要留私域入口（默认不留，先过平台合规）。
- 默认：先只做流量主，粉丝过 500 再开返佣带货。

第三轮收尾复述一句，然后直接进 Phase 2 出蓝图，不要再追加新问题。

## 追问与收尾规则

- 一次最多追问 2 次，仍答不出就按默认走 + 记假设项，不许把咨询做成审讯。
- 使用者中途给的新信息与前面答案冲突时，以最新答案为准，并回头改已复述的内容。
- 问卷全部答案整理成 `PROJECT_DIR/intake.md` 存档（题目+答案+假设标注），蓝图出错时回溯它，不许凭记忆答人设问题。
