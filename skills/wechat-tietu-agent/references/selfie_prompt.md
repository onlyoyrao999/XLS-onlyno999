# 自拍生图提示词模板与验脸清单

每张图一条提示词，基于本模板填空。用 `FACE_REF` 原图作参考图输入，禁止纯文字生图。

## 模板（中文主干，可按所用生图工具译英）

```
以参考图人物为唯一主角，严格保持同一张脸：脸型、五官、肤色、年龄感与参考图1:1一致，不美颜、不换脸、不改变发型<招牌元素按人设卡填写>。
人物穿搭（本篇统一）：<上装> + <下装> + <鞋> + <帽/无帽> + <配饰/道具>。
画面：<自拍机位，见下表>，人物在<地点>，背景是可辨认的<地标/场景细节>，<天气与时段>，手机前置摄像头拍摄质感，轻微广角，自然光，皮肤真实纹理，抓拍感，表情<具体表情>，动作<具体动作>。
画幅 3:4 竖图。
负向：不要换脸、不要变年轻或变老、不要磨皮塑料感、不要多余手指/畸形手、不要文字/水印/logo乱码、不要影楼摆拍、不要海报排版。
```

## 9 张图机位配比（单篇标准，可按立项卡微调）

| # | 机位 | 用途 |
|---|---|---|
| 01 | 近距离手持自拍（手臂微入镜），人+地标同框 | 封面，验脸基准张 |
| 02 | 半身自拍，换一个地标角度 | 展开 |
| 03 | 自拍杆远景全身，人小景大 | 交代地点全貌 |
| 04 | 镜面/橱窗反射自拍（有条件时） | 变化感 |
| 05 | 路人帮忙拍：人物站在地标正前 | 与自拍视角交替防单调 |
| 06 | 近景表情特写（本篇情绪点） | 情绪担当 |
| 07 | 与场景互动（摸碑/端食物/扶栏杆看景） | 故事感 |
| 08 | 背影或侧脸望向地标 + 回头一瞬二选一 | 氛围收尾前 |
| 09 | 再一张手持自拍，挥手/比心/招牌动作 | 收尾互动感 |

每篇 ≥3 张真自拍视角（01/02/06/09 里选），手臂入镜角度与持机方向全篇自洽（同一只手持机不许左右乱跳）。

## 验脸清单（每篇逐张过，不过重抽）

- [ ] 裁出脸部放大，与 `FACE_REF` 并排比：脸型/眉眼/鼻嘴/年龄感一致
- [ ] 发型与招牌元素与人设卡一致（或立项卡已注明替换）
- [ ] 手指数量与持机逻辑正常，配饰不穿模
- [ ] 穿搭 9 张是同一套（颜色/款式不漂移），与立项卡一致
- [ ] 地标可辨认且没张冠李戴（别把 A 地标生成成 B 地标）
- [ ] 无文字乱码/水印/多余人物抢镜（常驻配角除外，且配角也须对档验脸）
- [ ] 季节与天气全篇统一，光线方向大致一致

## 失败处理

- 封面张验脸不过：停，先修这一张（加强参考图权重/换种子重抽），过了才准批量。
- 同一张重抽 3 次仍漂移：换机位或换表情重设该张，并在发布包备注缺张（宁发 6 张合格的，不凑 9 张）。
- 整篇脸型系统性漂移：检查是否漏带参考图、参考图被压缩——修输入，不许靠加文字描述硬救。
